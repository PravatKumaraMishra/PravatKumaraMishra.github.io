# Personal Domain — GitHub Pages

Repository for the GitHub Pages site associated with `pravat.me`.

## Current contents

- `CNAME`: declares the custom domain `pravat.me`.
- `README.md`: repository documentation.

The current repository has no `index.html`, application source, package manifest, or build configuration. It does not yet contain a complete portfolio website.

## Add site content

Clone the repository:

```sh
git clone https://github.com/PravatKumaraMishra/PravatKumaraMishra.github.io.git
cd PravatKumaraMishra.github.io
```

Add an `index.html` page and any referenced assets. Open the page locally to review it before committing. There is no existing development or build command.

## Publishing

Review **Settings → Pages** in GitHub to choose a publishing source and confirm the custom domain. The `CNAME` file alone does not confirm that Pages is enabled or DNS is correctly configured. DNS must be configured at the domain provider as well. Preserve `CNAME` when updating the site if the custom domain should remain `pravat.me`.
